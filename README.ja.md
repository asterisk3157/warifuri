# warifuri

[English](README.md)

AI エージェントと一緒に仕事を進める人のための秘書です。

何のために、いつまでに、どこまでやるかは、使う人が決めます。いつ、どれを、どの順でやるかは、warifuri とエージェントが決めます。人が手放すのは計画を立てる手間で、約束は人が持ったままです。

> **いまの段階は設計です。** コードはまだありません。設計は `docs/` にあります(いまは日本語だけです)。友人の何人かに試してもらう間はリポジトリを非公開にし、この README だけで立てられると確かめてから、v0.1.0 で公開します。

## 考え方

- ゴールとタスクの台帳を1つ、自分のサーバーに置きます。ゴールには、使う人が決めたあるべき姿と期日があります。タスクは、そこへ向かう作業の1ブロックです。
- 台帳は MCP で開きます。各機械(Mac、Windows、ほかの PC)の Claude Code が、どのネットワークからでも HTTPS で同じ台帳を読み書きします。
- ほかは差し込みです。スケジュール、カレンダー、毎晩期日を見張る秘書、秘書と話すための Discord や Web 画面は、要るものだけを入れます。
- タスクは、作業したエージェントが閉じます。閉じ忘れは秘書が拾います。使う人は、いつでも上書きできます。
