# warifuri

[English](README.md)

AI エージェントと一緒に仕事を進める人のための秘書です。

## なぜ作ったか

大学院やフリーランスのように決まった時間割がない生活では、締切のあることをだらだら続けがちです。やることを書き出しても、いつ、どれをやるかを毎日自分で考えるのは重い作業です。

warifuri は、この「いつ、どれを」を AI に任せるために作りました。何のために、いつまでにやるかは人が決め、いつ何をやるかは AI が決めます。作者が自分用の秘書を2週間あまり動かし、その記録をもとに設計しました。

## どう動くか

中心にあるのは、ゴールとタスクの台帳です。台帳はサーバーに1つだけ置き、Mac や Windows の Claude Code から MCP で読み書きします。どの機械で作業していても同じタスクが見え、終わったらその場で閉じられます。

スケジュールやカレンダー、毎晩期日を見張る秘書は、台帳に差し込む形で足します。使わないものは入れなくても動きます。

サーバーは Mac、Windows、Linux で動き、独自ドメインは要りません。

## いまの状態

設計を終えて、台帳を作り始めたところです。まだ使える形にはなっていません。

考え方は[思想](docs/思想.md)、全体の形は[構成](docs/構成.md)にまとめています。
