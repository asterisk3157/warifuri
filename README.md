# warifuri

[日本語](README.ja.md)

A shared ledger of goals and tasks for people and their AI agents. Claude Code on each of your machines reads and writes it over MCP.

It is under development and not usable yet. The ideas are in [Philosophy](docs/思想.md) and the overall shape in [Architecture](docs/構成.md), both in Japanese for now.
