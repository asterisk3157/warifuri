# 週の完了確認(weekly)

warifuri が決まった時刻に「週の完了確認の時間です」と知らせてきました。この会話の中で、開いているタスクのうち、終わっていそうなのに閉じていないものを、根拠つきで本人に確かめます。毎晩の閉じ忘れ(`nightly.md` の手順7)は止まって見えるタスクだけを見ますが、ここでは週に1回、開いているタスクを全部見て、1週間の記録と、この会話で本人が話したことに突き合わせます。

閉じるのは、本人が了承したタスクだけです。`close_forgotten` の自律度が `act_then_tell` でも、ここでは自分で閉じません。ここでの根拠は推定が多いからです。

## 1. 読む

1. `proposals` を引数なしで読み、了承された案を行って `proposal_done` を付けます(朝の手引きと同じ)。
2. `proposals` を `which: "open"` と `which: "recent"` で読みます。答え待ちか、断られた閉じる案(`close_forgotten`)のあるタスクは、この回では聞きません。前に断られたものは、そのあとに新しい根拠が出たときだけ聞き直します(原則13)。
3. `board` を引数なしで読み、開いているタスク(`ready`、`running`、`waiting`、`deferred`)を集めます。
4. `activity` を、`from` に7日前の日付を渡して読みます。`more` が多いときは、日を分けて呼びます。
5. `reports` で、この1週間の報告を読みます。
6. `stale` を読みます。

## 2. 根拠を探す

タスクごとに、終わっていそうな根拠を探します。根拠にしてよいのは、次のものだけです。

- 記録: `activity` と `get` の記録。手放したときの `next` が終わりを書いている(「マージした」「提出した」など)、同じゴールの後ろのタスクに着手している、後ろのタスクが先に閉じた。
- 予定: `schedule` で、そのタスクの予定が過ぎていて、そのあと記録に動きがない。これだけでは根拠にせず、ほかの根拠を足すものとして使います。
- 会話: この会話で本人が「終わった」「出した」「もう要らない」と話したこと、スレッドの要点、エージェントからの依頼に書かれた結果。いつの、どの言葉かを書けるものだけにします。
- 報告: 毎晩と朝の報告に、終わったと書いてあるもの。

Git のコミットや使う機械のファイルは、サーバーから見えないので探しません。題名だけ似ているものは、根拠にしません。

根拠が1つもないタスクは、聞きません。止まっているだけのものは、毎晩と朝の仕事が扱います。

## 3. 聞く

本人がこの場にいないかもしれないので、短く書いてから `ask` で聞きます。

1. 返事は、確かめたいタスクの数を1行で書きます(「終わっていそうなタスクが **3件** あります。1件ずつ確かめます。」)。根拠のあるタスクがなければ、`ask` を呼ばず、「この1週間で、終わっていそうなのに開いているタスクは見つかりませんでした。」の1行だけにします。
2. 根拠の強いものから、多くても4件を、1回の `ask` で聞きます。1問ごとに次のようにします。
   - `header` は「完了確認」、`kind` は `close_forgotten`、`about` はそのタスクの id。
   - 問いには、タスクの題名と、根拠を1つか2つ、いつのどの記録かが分かる形で書きます(「11月6日に手放したときの次の一手が『マージ済み』です」)。
   - 選択肢は「閉じる」(おすすめ。成果は根拠から1行で書くと説明する)、「まだ続ける」、「やめる」の3つにします。
3. 5件目からは、`propose`(`kind: "close_forgotten"`、`about` はそのタスク)で1件ずつ案にし、本文に根拠を書きます。朝の秘書が、あとで聞きます。答えを待っている質問がすでにあって `ask` が断られたときも、同じく案にします。

## 4. 答えを受けて行う

答えは次の回にまとめて届きます。

- 「閉じる」: `close` で `done` にし、`result` に成果を1行と、「本人に確かめて閉じた。根拠: …」を書きます。
- 「やめる」: `close` で `discarded` にし、`reason` に本人の言葉を書きます。言葉がなければ、理由を聞きます。
- 「まだ続ける」: 何もしません。次の一手を本人が話したら、`update` で `next` に書きます。
- 「その他」の言葉: そのとおりに行います。意味がはっきりしないときは、聞き直します。

行ったことは、返事に1件1行で書きます。
