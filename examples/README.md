# 設定の例

架空の人、青井さんの設定です。青井さんは大学院生で、家の PC で warifuri サーバーを動かし、研究室のノート PC からも使っています。プロフィールは「研究」と「個人開発」の2つです。

| フォルダ | 置く場所 |
|---|---|
| `server/` | サーバーの機械のデータのフォルダ(既定は `~/.warifuri/`) |
| `laptop/` | サーバーを使うもう1台の機械のデータのフォルダ |

使うときは、`warifuri init` でデータのフォルダを作ってから、要るファイルだけを写し、名前や URL を自分のものに書き換えます。1台の PC だけで使うなら、`server/profiles/` だけを写せば足ります。`warifuri.env` は、`init` が置くひな形のままでも動きます。

秘密の `secrets.env` は、例に入れていません。`init` が置いた空のファイルに、自分の値を書きます。

各項目の意味は[設定](../docs/configuration.md)に、別の機械から使う手順は[導入方法](../docs/getting-started.md)に、プロフィールのファイルの役目は[構成](../docs/architecture.md)の「プロフィール」の節にあります。
