# Security

warifuri keeps your goals and tasks on a server that every machine reaches over the network, so a weakness in it can expose your plans or let someone change them.

## Reporting a problem

Please report vulnerabilities privately through [GitHub's security advisories](https://github.com/asterisk3157/warifuri/security/advisories/new), not in a public issue.

- Say what you found, how to reproduce it, and what an attacker could do with it.
- Do not include real keys, tokens, or the contents of anyone's tasks.

You will get a reply within a week. Once a fix is ready, the advisory is published with credit to you, unless you ask to stay anonymous.

## Supported versions

Security fixes go to the latest 0.1.x release and to `main`. Older releases are not patched, so please update to the latest one.
