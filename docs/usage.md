# 使い方

## AI エージェントに頼めること

warifuri に接続した Claude Code や Codex には、ふだんの言葉で頼めます。エージェントが warifuri のツールを選んで、データベースを読み書きします。

| 頼みたいこと | 言い方の例 | 使われるツール |
|---|---|---|
| ゴールを作る | 「v1 を出す、をゴールにして。期日は 11 月 30 日」 | `create_goal` |
| タスクに分ける | 「このゴールをタスクに分けて、やる順番も付けて」 | `create_task`、`link` |
| 次にやることを決める | 「次なにする」「このゴールの次は」 | `board`、`flow` |
| 作業を始める | 「この作業を始めるので、タスクを担当して」 | `search`、`start` |
| 作業を終える | 「終わったので、完了にして」 | `close` |
| 待ちにする | 「〇〇さんの返事待ちにして」 | `wait` |
| 先送りする | 「来週の月曜まで先送りにして」 | `defer` |
| 予定を見る | 「今週の予定を見せて」 | `schedule` |
| 作業の時間を取る | 「明日の午後に、このタスクの時間を2時間取って」 | `free_time`、`book` |
| 片づける | 「止まってるものある?」 | `stale` |
| 覚えてもらう | 「〇〇さんは月曜が休み、と覚えておいて」 | `note` |

期日を決めるのは人です。エージェントが自分で期日を作ることはありません。

## タスク確認

タスク確認は、エージェントがファイルを編集する直前に、担当中のタスクがあるかを確かめる仕組みです。ない場合は編集を止め、先にタスクを探すか作成して担当する(`start`)ようエージェントに伝えます。サーバーに接続できないときは止めません。

タスク確認が動くのは、作業フォルダとして登録したフォルダの中だけです。登録するには、そのフォルダでエージェントに「このフォルダを作業フォルダに登録して」と頼みます。止めたい場合は、`warifuri.env` に `WARIFURI_GATE=off` と書きます。

## Web UI

サーバーの起動中に http://127.0.0.1:8787/ を開くと、ゴール・タスク・予定を確認できます。ホストしている場合は、公開 URL を開いて GitHub でログインします。

## 秘書のスキル

Claude Code や Codex に「今日なにやる」「止まってるものある?」「次なにする」のように話しかけると、秘書のスキル `warifuri-secretary` が使われます。今日やることの整理、予定の確保、止まっているタスクの片づけ、次の一手の提案をします。データを変えるのは、あなたが了承したものだけです。

秘書(下の節)を有効にしていなくても使えます。

## 秘書

秘書は、タスク管理と予定調整を定期実行する AI エージェントです。サーバーの PC で動き、次の時刻に仕事をします。有効にする方法は[導入方法](getting-started.md#秘書)にあります。

| 時刻 | 仕事 |
|---|---|
| 毎日 23:00 | ゴールが期日に間に合うかを確かめ、予定を組み直す |
| 毎日 07:00 | 朝のあいさつをして、決めてほしいことを聞く |
| 日曜 23:00 | 受信箱(エージェントの気づきがたまる場所)を整理する |

### 秘書と話す

Web UI の「秘書」(`/secretary`)で話せます。

- 書いて送ると、秘書がデータベースを確かめて返事をします。
- 画像やファイルを添付できます。
- 秘書が選択肢で聞きたいことがあると、質問のカードが表示されます。
- 発言ごとにスレッドを開いて、別の話を続けられます。
- 07:00 の分は、この会話に「定期実行」の印つきで届きます。

### 秘書に任せる範囲

秘書は、組み直しや閉じ忘れの片づけなどを、初めは毎回聞いてから行います。同じ種類の案を3回続けてそのまま了承すると、それからは、行ってから知らせるようになります。外に出すものや取り返しのつかないもの(あなたの予定を消すなど)は、任せられません。

## エージェント・秘書のスキル・秘書の違い

| | いつ動くか | 何をするか | データを変えるもの |
|---|---|---|---|
| エージェント | 作業を頼まれたとき | 1つのタスクを担当して、やりきる | 自分が担当するタスク |
| 秘書のスキル | 「今日なにやる」などと頼まれたとき | 全体を整理して、案を出す | その場であなたが了承したもの |
| 秘書 | 決まった時刻と、話しかけられたとき | 期日に間に合うかを見張り、組み直す | 任された範囲のもの |
