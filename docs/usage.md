# 使い方

warifuri に接続すると、Claude Code や Codex が、ユーザーと同じゴール・タスク・予定を見ながら作業するようになります。

## 1. AI エージェントができるようになること

| できるようになること | 頼み方の例 |
|---|---|
| ゴールをタスクに分け、やる順番を付ける | 「v1 を出す、をゴールにして。期日は 11 月 30 日。タスクに分けて、順番も付けて」 |
| 次にやることを決める | 「次なにする」「このゴールの次は」 |
| 作業の前にタスクを担当し、終わったら完了にする | 「この作業を始めて」「終わったので完了にして」 |
| 待ちや先送りを記録する | 「〇〇さんの返事待ちにして」「来週の月曜まで先送りにして」 |
| 空いている時間に作業の時間を取る | 「明日の午後に、このタスクの時間を2時間取って」 |
| 止まっているタスクを片づける | 「止まってるものある?」 |
| 人や決まりを覚えておく | 「〇〇さんは月曜が休み、と覚えておいて」 |
| 人を1人ずつ覚えておく(所属、メール、誕生日、好きなもの)。近い誕生日は秘書が知らせる | 「〇〇さんの誕生日は 4 月 1 日、紅茶が好き」「〇〇さんのことは消して」 |
| 今日やることを整理する | 「今日なにやる」 |

## 2. 仕組み

### MCP

エージェントは、頼まれた内容に合わせて、MCP で warifuri のツールを自動で使います。

### タスク確認

エージェントがファイルを編集する直前に、担当中のタスクがあるかを確かめる仕組みです。ない場合は編集を止め、先にタスクを担当するようエージェントに伝えます。これで、どの作業がどのタスクのためのものかが、いつも記録に残ります。

タスク確認が動くのは、作業フォルダとして登録したフォルダの中だけです。登録するには、そのフォルダでエージェントに「このフォルダを作業フォルダに登録して」と頼みます。止めたい場合は、[設定](configuration.md)で止められます。

### 作業の終わりの確認

エージェントが作業を終えるとき、担当中のタスクが残っていれば、済んでいれば完了に、途中なら次の一手を書いて手放すよう伝えます。担当したまま閉じ忘れるのを防ぎます。伝えるのは1つの会話で一度だけで、まだ続ける作業なら、エージェントはタスクを持ったまま終えられます。止めたい場合は、[設定](configuration.md)で止められます。

### 会話の始めの要点

作業フォルダでエージェントとの会話を始めると、そのフォルダで担当中のタスク、プロフィールのナレッジの目次、人の一覧がエージェントに渡ります。渡るのは見出しとファイル名、人の名前と所属・役割だけで、本文はエージェントが必要なときに読みます。止めたい場合は、[設定](configuration.md)で止められます。

## 3. 秘書

秘書は、タスク管理と予定調整を定期実行する AI エージェントです。サーバーの PC で動き、ユーザーが頼まなくても、決まった時刻に全体を見て整えます。既定ではオフで、有効にする方法は[導入方法](getting-started.md#秘書)にあります。

| 時刻 | 仕事 |
|---|---|
| 毎日 23:00 | ゴールが期日に間に合うかを確かめ、予定を組み直す |
| 毎日 07:00 | 朝のあいさつをして、決めてほしいことを聞く |
| 日曜 23:00 | 受信箱(エージェントの気づきがたまる場所)を見て、整理の案を出す |
| 1時間ごと(夜を除く) | カレンダーの予定を取り込む(カレンダーを渡したときだけ) |

秘書を有効にすると、エージェントの気づきはすぐにはナレッジにならず、受信箱に入ります。

### 秘書と話す

Web UI の秘書の画面から話しかけます。秘書が選んで答えてほしいことは、質問のカードで聞いてきます。カードは1枚ずつ出て、全部に答えるか「あとで」を押してから、秘書がまとめて動きます。

設定がまだないうちは、最初に話しかけたときに、秘書が生活の決まり、予定を置いてよい時間、週の決まった場所、プロフィールを、1つずつ聞いて一緒に作ります。区分ごとに書く中身を見せてから書くので、了承しなければ何も書きません。「あとで」と答えれば、それからは聞きません。あとで作るときは「設定を一緒に作りたい」と話しかけます。作った設定は、設定の「自身について」で見られます。変えるときも、秘書に話しかけます。

### 任せる範囲

秘書は、予定の組み直しや閉じ忘れたタスクの片づけを、初めは毎回ユーザーに聞いてから行います。同じ種類の案を3回続けてそのまま了承すると、それからは、行ってから知らせるようになります。一度でも取り消すと、また聞くように戻ります。外に出すものや取り返しのつかないもの(ユーザーの予定を消すなど)は、任せられません。

### 外の道具

秘書には、Google カレンダー、Gmail、Notion のような外の道具を渡せます。既定では何も渡しません。渡すときは、道具ごとに範囲を決めます。

| 範囲 | 秘書ができること |
|---|---|
| 読むだけ | 読むことだけ。書こうとすると止まる |
| warifuri が作ったものだけ書く | 読むことと、秘書が入れた予定を書き出すこと。ユーザーが入れた予定は書き換えない |
| 書ける | 読むことと書くこと。メールを送るなど外に出すときは、毎回ユーザーに聞く |

たとえば、カレンダーは「warifuri が作ったものだけ書く」、メールと Notion は「読むだけ」にすると、秘書はメールからも予定や締切に気づき、決めた予定をカレンダーに書き出せます。設定の仕方は[連携の例](integrations.md)にあります。

### ほかのエージェントとの分け方

全体を整えるのは秘書だけです。秘書の報告、案、質問、任せる範囲を書けるのは秘書だけで、ほかのエージェントからは書けません。

Claude Code や Codex には、「warifuri」のスキルも入っています。スキルは、Claude Code や Codex が、頼まれた内容に合わせて読む手引きのファイルです。warifuri のスキルを読んだエージェントは、「今日なにやる」「止まってるものある?」「時間を取っておいて」と頼まれたときに、データベースを読んで手伝います。秘書が無効なら、その会話の間だけ秘書の代わりをし、「この日が空いているので入れておきますね」のように予定の案を出します。

| 秘書 | warifuri のスキルを使うエージェント |
|---|---|
| 無効 | 今日やることの整理や片づけを、その場でユーザーの了承を得て行う |
| 有効 | 予定や候補の一覧を見せるだけにし、整理と片づけは「秘書の画面で頼んでください」と伝える。予定は自分で入れず、秘書に頼む |

秘書が有効なとき、予定を入れる・動かす・消すのは秘書だけです。エージェントは、何に、どれくらいの時間を、いつまでに、どの時間帯がよいかを秘書に伝え、いつにするかは秘書が決めます。頼んだことと秘書の返事は、秘書の画面にも出ます。秘書の返事が1分半たっても届かないときは、エージェントが「秘書に頼みました」と伝え、決まったら秘書の画面に出ます。

ユーザーが名指しで頼んだ予定のほかの1件の操作(このタスクを閉じる など)は、どちらの場合もエージェントがその場で行います。

### 予定の決め方

秘書は、エージェントに時間を頼まれると、その1件だけで日時を決めず、今日から1週間の計画に足して入れます。返事には、何をいつ入れたかが書かれます。入れる順番は次のとおりです。

1. ユーザーが秘書に言った優先順(「金曜まではこれを先に」「これが終わったら次はこれ」)
2. 期日の近さ
3. タスクの順序

期日までに入らないときだけ、秘書がユーザーに、ほかの予定を動かすか、期日を変えるかを聞きます。AI だけで進められるタスクは、ユーザーの時間を取らないので、予定に入れずに「今すぐ進めてよい」と返します。

会社の VPN のように家でしかできない作業は、秘書に「これは家でしかできない」と伝えると、家にいる時間にだけ入ります。いる場所は、場所を書いた予定、週の決まった場所(「月曜の午後は研究室」など)の順に決まり、どちらもない時間は家にいるとみなします。どの場所が家かは、秘書に伝えて設定に入れます。

| | タイミング | 何をするか | データを変えるもの |
|---|---|---|---|
| エージェント | 作業を頼まれたとき | 1つのタスクを担当して、やりきる | 自分が担当するタスクと、頼まれた1件 |
| 秘書 | 決まった時刻と、話しかけられたとき | 期日に間に合うかを見張り、組み直す | 任された範囲のもの |

## 4. Web UI の見かた

サーバーの起動中に http://127.0.0.1:8787/ を開きます。サーバーと同じ PC で開く場合は、ログインは要りません。ホストしている場合は、公開 URL を開いて GitHub でログインします。画面は30秒ごとに新しくなります。

| 画面 | 説明 |
|---|---|
| カレンダー | 1日か1週間の予定が見られます |
| タスク | ゴールと、それに関するタスクが見られます |
| 秘書 | 秘書との会話。報告や質問もここに届きます |
| ナレッジ | 人、生活リズム、よく行く場所、曜日ごとの居場所、GitHub と、プロフィールごとの決まったこと、手順、未整理のメモ |
| サーバー | サーバーの版と動いている時間、つないでいる PC ごとの最後の接続と、担当中のタスク |
| 設定 | ユーザーのプロフィール(名前・色・自己紹介)、作業フォルダ、デバイス、GitHub ログインで接続したアプリ |

### 秘書の画面

秘書の画面は、秘書との会話の窓です。ユーザーの発言は右、秘書の発言は左に出ます。秘書が決まった時刻に動いたときの発言には「定期実行」の印が付きます。

- 送る: 下の欄に書いて送ります。ファイルは、クリップのボタン、ドラッグ、貼り付けで添えられます(1つ 5 MB まで、4個まで)。
- 音声入力: 送るボタンの右のマイクのボタンを押して話すと、話している途中から言葉が欄に入ります。もう一度押すか、送るボタンを押すと止まります。Chrome と Safari で使えます。Arc のようにブラウザの音声認識を使えないブラウザでは、Mac の音声入力(fn キーを押しながら F5)を使います。
- 質問に答える: 秘書が選んで答えてほしいことは、会話の下に質問のカードで出ます。1問ずつ答え、全部に答えるか「あとで」を押すと、秘書がまとめて動きます。答えたあとでも、答えを変えられます。
- 返事の候補: 秘書の返事の下にボタンが出ることがあります。押すと、その言葉を送ったことになります。書いて答えてもかまいません。
- スレッド: 発言ごとに、右の窓で別の話を続けられます。長くなりそうな話はスレッドで話し、要点は秘書がメインの会話でも覚えています。
- エージェントからの依頼: Claude Code や Codex が秘書に予定を頼むと、その依頼と秘書の返事が会話に出ます。

秘書が無効なときは、会話を見られますが、送ることはできません。

### ナレッジの画面

左の一覧から見るものを選びます。上に、人、生活リズム、よく行く場所、曜日ごとの居場所、GitHub が並び、その下にプロフィールが並びます。プロフィールを押すと開き、決まったこと、手順、未整理のメモが出ます。未整理のメモは、エージェントの気づきがたまる受信箱です。

- 人: すべてのプロフィールの人が1つの表に出ます。名前や所属で探す、所属で絞り込む、列の見出しで並べ替える、ができます。行を押すと、その場で開き、列、プロフィール、プロフィールごとの項目、種類ごとのメモ、つながりが全部出ます。名前の行をもう一度押すと閉じます。
  - エージェントや秘書が推測で書いた値には「推測」の印が付きます。
  - 直す: 行の右の鉛筆を押すと、その行が入力欄になります。Enter か ✓ で保存し、Esc か ✕ でやめます。空にして保存すると、その値が消えます。直した値はユーザーの言葉として残り、「推測」の印は外れます。
- 秘書と話す: 人を開くと、右下に丸いボタンが出ます。押すと右に欄が開き、その人のことを書いて送ると、秘書がその1回だけ動いて、確かな情報として書きます。「冬木さんは来月から副部長」のように、ほかの人のことも書けます。秘書が書いた行は、左の表で数秒のあいだ緑になり、「今 更新」と出ます。欄のやりとりは画面を開いているあいだだけ残り、秘書との会話には残りません。秘書が無効なときは登録できません。
- Claude Code や Codex との会話で人のことを言っても、エージェントが人に書きます。言ったことは確かな値になり、エージェントの推測には「推測」の印が付きます。
- 生活リズム、よく行く場所、曜日ごとの居場所、GitHub: 秘書が予定を組むときに読む設定です。行を押すと直せます。
- 決まったこと、手順、未整理のメモ: 見るだけです。直したいときは、エージェントか秘書に頼みます。
