# 連携の例

## Google カレンダー

warifuri は、Google カレンダーに直接は接続しません。カレンダーを読み書きするのは、ユーザーのエージェントです。エージェントに Google カレンダーの MCP を接続しておけば、warifuri の予定と組み合わせて使えます。

### 予定を取り込む

会議などのもとからある予定を warifuri に取り込むと、作業の時間をその予定と重ならないように組めます。

> 「今週の Google カレンダーの予定を、warifuri に取り込んで」

エージェントはカレンダーの予定を読み、warifuri に固定の予定として入れます。予定には、カレンダーのどの予定にあたるかの印(`source` と `external_id`)が付くので、同じ週を何度取り込んでも予定は増えません。カレンダーで予定を動かした場合は、取り込み直すと warifuri の予定も動きます。

### 作業の時間を書き出す

warifuri で取った作業の時間を、ふだん使っている Google カレンダーにも入れられます。

> 「明日取った作業の時間を、Google カレンダーにも入れて」

エージェントはカレンダーに予定を作り、その予定の id を warifuri の予定に付けます。warifuri が直すのは、こうして書き出した予定だけです。ユーザーが自分で入れた予定を、書き換えたり消したりすることはありません。

### 秘書にカレンダーを使わせる

秘書は、既定ではカレンダーを使えません。毎晩の組み直しでカレンダーも見てほしい場合は、サーバーの PC の `warifuri.env` に、秘書に使わせるカレンダーの MCP のツールを書きます。

```
WARIFURI_SECRETARY_CALENDAR_TOOLS=mcp__<カレンダーの MCP サーバーの名前>
```

claude.ai のコネクタのカレンダーを使わせる場合は、あわせて `WARIFURI_SECRETARY_CONNECTORS=on` と書きます。どちらの場合も、秘書が使えるのはここに書いたツールだけです。カレンダーへの書き出しは、初めは毎回ユーザーに聞いてから行います。
